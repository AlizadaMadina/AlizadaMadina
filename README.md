## Projects I'm proud of

### 🧠 Alzheimer's Disease Predictor
**Clinical ML web app deployed on Streamlit**  
Built an end-to-end ML pipeline that classifies patients into diagnostic categories (Nondemented, Demented, Converted) using the OASIS longitudinal clinical dataset. Used GroupKFold cross-validation to prevent data leakage across 150 patients and 373 visits. Achieved 71.29% cross-validated accuracy with a Random Forest model.

🔗 [Live app](https://alzheimers-predictor-madina.streamlit.app) · [GitHub repo](https://github.com/AlizadaMadina/alzheimers-predictor)

**Stack:** Python · scikit-learn · Streamlit · pandas · GroupKFold

### 📊 Canadian Substance Use Dashboard
**Public health data visualization published on Tableau Public**  
Built an interactive dashboard exploring how alcohol, cannabis, and opioid use varies across age groups in Canada using real Health Canada survey data from 36,000+ respondents. Engineered a Python and pandas data pipeline in Jupyter Notebook to clean and combine 3 government CSV files into a unified 638-row analytical dataset. Key finding: 15-19 year olds have the highest non-medical opioid misuse rate in Canada at 23%, higher than any other age group.

🔗 [Live dashboard](https://public.tableau.com/app/profile/madina.alizada/viz/Book1_17787142620000/Dashboard1) · [GitHub repo](https://github.com/AlizadaMadina/canada-substance-use-dashboard)

**Stack:** Python · pandas · Jupyter · Tableau Public · GitHub
